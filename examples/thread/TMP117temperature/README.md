# TMP117 temperature

7Semi_TMP11x library and its dependencies. Use a breakout compatible with 3.3 V logic.

## Wiring

Connect SDA to GPIO12, SCL to GPIO22 and share ground. Supply the breakout at its rated voltage.

## Run

Follow the [Thread commissioning and build instructions](../README.md).

## Bench check

Compare the °C output with a reference. Change the input and confirm a new report.

Arduino Library Manager driver: **7Semi TMP11x** 1.0.0.
