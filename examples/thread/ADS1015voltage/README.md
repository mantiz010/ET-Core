# ADS1015 voltage

Adafruit_ADS1X15 Arduino driver and a 3.3 V compatible breakout.

## Wiring

SDA GPIO12, SCL GPIO22, 3.3 V and GND. Wire a known 0–3 V test signal to A0 with common ground.

## Run

Follow the [Thread commissioning and build instructions](../README.md).

## Bench check

Vary the input and compare the reported V reading to an independent reference.
