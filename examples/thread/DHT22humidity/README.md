# DHT22 humidity

DHT sensor library and Adafruit Unified Sensor.

## Wiring

DATA to GPIO4 with a 4.7 kΩ pull-up to 3.3 V. Supply a 3.3 V compatible module.

## Run

Follow the [Thread commissioning and build instructions](../README.md).

## Bench check

Compare humidity with a reference. Unplug the probe and check the sensor error.

Arduino Library Manager driver: **DHT sensor library** 1.3.9.
