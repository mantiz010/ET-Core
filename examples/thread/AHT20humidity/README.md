# AHT20 humidity

Adafruit_AHTX0 library and its dependencies. Use a breakout compatible with 3.3 V logic.

## Wiring

Connect SDA to GPIO12, SCL to GPIO22 and share ground. Supply the breakout at its rated voltage.

## Run

Follow the [Thread commissioning and build instructions](../README.md).

## Bench check

Compare the % output with a reference. Change the input and confirm a new report.

Arduino Library Manager driver: **Adafruit AHTX0** 2.0.6.
