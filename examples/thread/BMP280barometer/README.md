# BMP280 barometer

Adafruit_BMP280 Arduino driver and a 3.3 V compatible breakout.

## Wiring

SDA GPIO12, SCL GPIO22, 3.3 V and GND. Use the driver default address or the explicit address in the sketch.

## Run

Follow the [Thread commissioning and build instructions](../README.md).

## Bench check

Vary the input and compare the reported hPa reading to an independent reference.
