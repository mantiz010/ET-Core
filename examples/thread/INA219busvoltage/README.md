# INA219 bus voltage

Adafruit_INA219 Arduino driver and a 3.3 V compatible breakout.

## Wiring

SDA GPIO12, SCL GPIO22, 3.3 V and GND. For INA219, connect VIN− to the positive terminal of the low-voltage source being measured and share ground.

## Run

Follow the [Thread commissioning and build instructions](../README.md).

## Bench check

Vary the input and compare the reported V reading to an independent reference.
