# Capillary bulb thermostat

Voltage-free NO/COM model of the capillary bulb thermostat.

## Wiring

GPIO4 to NO, GND to COM. Internal pull-up enabled. Contact closure is active.

## Run

Follow the [Thread commissioning and build instructions](../README.md).

## Bench check

In Home Assistant watch the binary entity while you warm the remote bulb through its set point. Verify both transitions.
