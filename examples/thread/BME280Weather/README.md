# BME280 weather

BME280 breakout and Adafruit BME280 library with its dependencies.

## Wiring

3.3 V and GND. Connect SDA to GPIO12 and SCL to GPIO22. Select 0x76 or 0x77 on the breakout.

## Run

Follow the [Thread commissioning and build instructions](../README.md).

## Bench check

Compare temperature, humidity and hPa against a reference at room conditions.

Arduino Library Manager driver: **Adafruit BME280 Library** 1.0.7.
