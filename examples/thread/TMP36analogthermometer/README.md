# TMP36 analog thermometer

TMP36 analog temperature IC.

## Wiring

Use the part package pinout. Supply 3.3 V and GND, Vout to GPIO1, 100 nF bypass at supply pins.

## Run

Follow the [Thread commissioning and build instructions](../README.md).

## Bench check

At 25 °C, check the output with a voltmeter and compare the reported temperature.
